## 已驗證（模擬環境）

- 交易權限：設定頁與對話框為同一控制；「僅分析」無交易工具；「逐筆確認」可下單並經 App 核可卡。
- 核可：Claude Code、Codex、Pi 核可等待超過 90 秒仍可送出；180 秒逾時顯示「已逾時，未送出」且不可再按；
  停止／Esc 立即使待核可卡顯示「已停止，未送出」；重載後未決卡片顯示「已取消，未送出」，不重送。
- 刪單：逐筆確認刪單經券商回讀確認為 Cancelled；刪單卡逾時後同一對話可重新出卡並完成刪單。
- 重載接回：Claude Code、Codex、Pi 重載後回合自行結束，不出現重複卡片。
- 工作階段管理：閒置的其他模型服務不阻擋連線測試；同服務阻擋時以中文說明並可停止。
- Pi：官方 v0.85.0 下載（SHA256 核對）至 App 自有資料夾，沿用既有 OpenAI 登入；下單、刪單經 App 核可卡。
- 介面：Codex 式輸入框（送出／停止、排隊、附件、「＋」選單）、推理強度滑桿（最高／極限、夾限提示）、
  Context 用量面板（僅顯示模型服務實際回報的欄位）、工具列摘要、「思考了 N 秒」、程式碼上色、深淺色與窄版。

每輪下的模擬委託皆已取消並以券商回讀確認，期貨帳戶測試結束時無在途委託。
