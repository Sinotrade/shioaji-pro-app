## 最終行為

| 項目 | 行為 |
| --- | --- |
| 實際成交與成交組 | 只畫 `Trade.status.deals` 的實際成交，買 ▲、賣 ▼ 的尖端錨定所屬 K 棒與成交價。同棒、同合約月份、同方向、同單位合組；單價組在該價，多價組在最低買價／最高賣價，區間線與刻度保留真實價位，價格標籤寫「均」與合計。 |
| 樣式與配色 | 圖表設定提供「不畫／三角形／買賣／價格」；不畫只關這張圖，樣式為全域偏好。標籤是半透明玻璃底；預設藍買橘賣，可選「同 K 棒」。 |
| 工具列與設定 | 「成交」開關控制本圖標記與明細，「明細 N」含無對應 K 棒的成交。圖表設定有「成交標記」分頁；重開停在此頁先解除點價武裝，有分頁時 Esc／完成把焦點還給「圖表下單設定」鈕。 |
| 提示框 | 最多列 4 筆，顯示整棒筆數、合計及多價位均價摘要；滑到的價位先列。跨合約或全部帳戶時，合約／帳戶放每筆第二列，寬窄框一致。窄框（圖表區小於 380px）時間只到秒、放不下時換行；寬框與清單到毫秒。 |
| 明細清單 | 只列最新 500 筆，其中保留 50 個名額給無對應 K 棒的成交，顯示較早未列筆數；換月日多「合約」欄。清單可鍵盤聚焦、內部捲動。 |
| 這根 K 棒 | 滑過有成交的 K 棒、提示框出現後，再按「明細」，清單捲到那根、標亮那幾列，頂端一行摘要，旁邊「×」可取消。不設時間限制，但用一次就忘，關掉再開不會再出現；換商品、週期、帳戶、環境、關掉成交標記，或已確認時那根已經沒有成交，都會取消清單上的標示。 |
| 此棒摘要與上限 | 單一價位也顯示價格，如 `▲ 買 3 口 · 12,345`；多價位和提示框同格式，如 `▲ 買 22 口 · 均 12,345.6 · 12,340～12,350`。超出 500 列時寫「此棒成交未列於目前清單」或「此棒另有 N 筆未列於目前清單」，不突破上限；打開時不搬鍵盤焦點，新回報不再捲動。 |
| 全部帳戶 | 同市場所有可交易帳戶合併顯示，不同帳戶可合成同組，明細逐筆列帳戶並套隱私遮罩；不收其他市場帳戶。 |
| 資料來源閘門 | `fillsReady` 預設未確認；須目前環境的委託經權威查詢確認、沒有待對帳、串流即時且成交數量與明細一致。工具列與明細說明待對帳原因；未確認不畫新資料，上次確認標記可淡色保留、不可滑過且不列舊明細。範圍改變或主視窗鏡像失效即清掉。 |
| 時間對齊 | N 分 K／日 K 由 1 分 label 聚合；收盤寬限內定盤併入該時段最後一根。即時 K 棒按原始 tick 時間分桶，成交先找歷史桶再找即時桶。連續月換月日以近月最後交易日 13:30 分界，之前收前月、之後收目前月份。 |
| 正式環境 wire | 期權委託回報可能為 `exchange: 'TIM'`、`target_code: null`、`code: full_code`；期權不比交易所，股票仍比對。委託 wire 有真實去識別 fixture，Deal payload 的正式樣本仍缺。 |
| 請求數 | 和基底相同，只多一次換月合約查詢（當日委託有換月相關合約時才查）。 |
| 效能機制 | 每張委託投影快取沿用不變的成交，也沿用內容相同的鏡像；明細檢查與投影共用範圍篩選，同棒換價位沿用摘要。大量時合併連續回報；關掉標記時明細檢查與合併計時器零成本，釋放投影快取及保留組的逐筆成交。窄於 3px 時，多價組的各價位座標只取兩端。 |

## 重現方式（示範頁）

示範頁目錄：`scripts/chart-fills-demo/`。啟動：

```sh
pnpm exec vite --config scripts/chart-fills-demo/vite.config.ts --port 5298
```

網址：`http://127.0.0.1:5298/`；壓力測試例：`/?stress=20000&live=20&quote=10`。

| 參數 | 範圍與作用 |
| --- | --- |
| `stress=N` | 0–200000，產生 N 筆示範帳戶 A 的成交 |
| `live=R` | 0–200，每秒在最新一根追加 R 筆 |
| `quote=Q` | 0–200，每秒 Q 次合成報價 |
| `mirror=1` | 每秒把整份委託換成內容相同的複本，模擬彈出視窗的鏡像 |

`live`、`quote`、`mirror` 只在有 `stress` 時有效。壓力模式的全域函式（只在有 `stress` 時存在）：`window.__stressStop()`：停止回報、報價與鏡像。`window.__stressStats()`：回傳 `{ fills, quotes, total }`。
控制列：商品、主帳戶、深色／淺色、成交標記（三角形／買賣／價格）、顯示帳戶（目前帳戶／全部帳戶）、密集成交、待確認、新增一筆示範成交。

| 情境 | 操作與觀察 |
| --- | --- |
| 多價位組 | 開「密集成交」，觀察區間、均價標籤與提示框摘要 |
| 淡色保留 | 按「待確認」，觀察舊標記淡色保留及待確認說明 |
| 帳戶隔離 | 切主帳戶或按「新增一筆示範成交」，切回商品與帳戶核對 |
| 這根 K 棒 | 滑過有成交的 K 棒、提示框出現後再按「明細」，觀察摘要、標亮與「×」 |

`quote` 會把今天最後一根對齊現在時間，並丟掉晚於現在的 K 棒。13:30 前跑時，今天晚於現在的壓力成交（09:00 前是今天全部）會當成等待新 K 棒，既不畫也不列在明細，「明細 N」會少於 `stress`；要互相比較的量測請在 13:30 後跑。
換月日示範頁做不出來，只有單元測試涵蓋。

## 已知限制

| 項目 | 限制 |
| --- | --- |
| 成交序號拼法 | 暫存成交重播只認序號完全相同；讀回若用另一種拼法（如 `000001` 對 `1`），可能重複累加。目前真實資料都是同一種拼法，未經 wire 證實會發生；簡單防線會誤判真的同價同量兩筆，因此沒有加防護。 |
| 明細未齊 | 權威讀回的列成交數量大於明細時，圖表持續顯示「成交明細缺漏」，須等 sidecar 回傳完整明細。 |
| 壞資料 | 完整性檢查看原始明細加總，投影會去重、濾壞欄位，兩者可能不一致；目前取寧可不畫的方向，壞資料上游已擋。 |
| 均價 | 均價標籤不是任何一筆的真實成交價；寫「均」字，三角形與刻度在真實價位。相距很遠的價位須滑過或看明細。 |
| 標籤擁擠 | 「價格」樣式只放同一高度，擠時只剩三角形。 |
| 清單上限 | 只列最新 500 筆，「這根 K 棒」也不突破上限。 |
| 無對應棒 | 盤後定價、盤後零股、鉅額在分 K 沒有對應 K 棒，只列明細最後。 |
| 矮面板 | 開明細會把圖表區壓得很小。 |
| 極大量 | 5 萬筆以上加密集回報偶爾掉幀。 |
| 價格位數 | 取自跳動級距；期權級距表預取失敗，且 OHLC 讀值與最高／最低都關掉時，可能多一次唯讀級距查詢。 |
| 彈出視窗 | 主視窗在背景時計時器可能被節流，鏡像逾時會清掉保留的淡色標記，採保守行為。 |
| 淺色主題 | 部分文字（琥珀色字、「同 K 棒」配色的綠字）對比低於 4.5:1，是全站顏色，和既有「最高／最低」標籤同一組，另開主題 PR 處理。 |

最終審查從交易安全與正確性、效能、介面、架構與測試四個角度看整份改動，再由反方逐條複查。確認並修正的問題：

- 標示「這根 K 棒」時，摘要改用每價分組計算（日 K 今天那根上萬筆時，每次回報少約 3 ms）。
- 「明細」按鈕不再留住整份成交，關掉標記後即使沒有後續 render 也會釋放。
- 窄提示框在日 K 帶毫秒時會裁掉數量單位，改為只到秒、可換行。
- 清單的 `aria-describedby` 只指摘要行，不再念「×」的名稱；成交鈕說明改指「圖表下單設定」。
- 委託快照的環境標記改用 `currentProtectionEnv()`，不再自己組字串。
- 設定分頁內容的操作由彈出層統一先解除點價武裝，分頁不必自己接。
- 停留門檻測試改用假時鐘驗行為；註解整理。
