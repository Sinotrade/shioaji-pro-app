fix(search): 修正櫃買指數名稱搜尋缺漏，並整理搜尋結構與相關商品、ETF 顯示

## 變更內容 / Summary

這個 PR 原本是要修正櫃買指數用名稱搜尋不到的問題。修正後，再整理名稱搜尋的資料來源與請求結構，減少重複工作，並優化同標的相關商品及 ETF 的顯示方式。介面樣式與窄視窗的調整，是驗收時順帶處理的項目。

### 問題與原因

- 原先輸入「櫃買」只會找到櫃買期貨，輸入「櫃買指數」則是空清單。但輸入完整代碼 `IX0043` 可以找到，代表 API 有這個商品。問題出在名稱搜尋，與報價連線無關。
- 名稱搜尋的指數清單只包含 `IX0001`（加權）與上市類股指數，漏了 `IX0043`，輸出的交易所也一律寫死為 `TSE`。完整代碼走的是直接查合約的另一條路，不經過這份清單，因此兩種輸入的結果不一致。
- 延伸檢查時也發現幾個問題：
  - 以名稱或股票代碼搜尋，只會列出現股。
  - 券商批次目錄的名稱覆蓋不完整。
  - 內建 ETF 名稱快照不會反映新上市或更名。

### Before / After

| 輸入 | Before | After |
| --- | --- | --- |
| 櫃買指數 | 空清單 | 找到 `IX0043`，交易所為 OTC |
| 櫃買 | 只有櫃買期貨 | 櫃買指數與櫃買期貨都會列出 |
| 台積電／2330 | 只有現股 | 現股、期貨近次月與權證依序列出 |
| 00981 | 可能先列 009810、009811 | 00981A／B／D／T 等同系列 ETF 優先 |

### 修改

- 補上 `IX0043` 的名稱與別名，交易所改為逐筆標示。名稱候選會再與券商目前有效的指數合約交集核對。這不是另建一份可交易清單，也不會每次輸入都逐檔抓取完整指數資訊。指數仍維持不可下單。
- 修正拖放 callback 參照不穩、導致自選列 memo 失效的問題。搜尋造成的整份自選重繪因此減少，行情也不會被清空。
- 窄視窗工作區改為直向顯示並停用拖放縮放，不覆寫桌面版面。同時修正快速縮放與手勢造成的欄位密度錯誤回寫。

### 最佳化

- **搜尋分層**：商品身分、名稱來源、關聯排序、請求共享與取消、UI 呈現各自負責。
  - 商品是否存在，以及類型、交易所、代碼，一律以券商即時合約為準。
  - 官方名稱來源只補名稱與別名，不會產生券商尚未支援的商品。
- **減少重複工作**：
  - 目錄與查詢共享資料，請求採有界佇列，並可取消。
  - 名稱更新時只重組必要部分，換關鍵字不會重抓整份名稱或合約。
  - 名稱來源改為背景批次刷新，搜尋不必等待外網；刷新失敗時沿用最後一份有效資料。
- **結果穩定**：
  - 分段回傳的結果依既定順序補齊，不會因為權證先回來就排到期貨前面。
  - 輸入變更、關閉或商品異動後，舊的回應不會覆蓋新的查詢。
- **相關商品顯示**：用名稱或股票代碼都能列出同標的商品。
  - 台積電依序為：現股 → 一般近月 → 小型近月 → 一般次月 → 小型次月 → 權證。
  - 台指先列一般、小型、微型近月，再以同樣順序列次月。
  - 缺少的規格會略過；同一實體月份的連續合約不重複列出；也不會從模糊比對的第一筆任意選定標的。
- **ETF 顯示**：
  - 輸入 `00981` 時，已確認為 ETF、且數字前綴相同的字母尾碼代號（00981A／B／D／T）會排在同樣有效的 009810、009811 之前。
  - 完整輸入 `009810` 時，仍以精確代碼優先。
  - 字母尾碼只用於系列排序，不用來判斷是否為主動式 ETF。

### 新增

- 新增官方 ETF 與上市、上櫃、興櫃一般股的名稱與別名來源。正式名稱與既有別名都可搜尋，但結果仍須符合券商目前的代碼與市場。
- 輸入精確股票代碼並帶有選擇權意圖、但目錄缺少名稱時，只會對唯一有效的股票補查一次名稱。補查結果不寫入報價，也不修改原合約。
- 搜尋介面調整：
  - 股票／ETF／期貨／選擇權／權證／指數加上文字分類與淡色卡片，顏色跟隨自訂主題。
  - 毛玻璃效果只套用在背景，文字維持不透明。瀏覽器不支援或系統開啟減少透明度時，改用不透明底色。
  - 搜尋列維持單行，所有寬度都是代號在前、名稱在後。窄版只在視覺上先收起類別與補充資訊，完整內容仍保留。
  - 目前選取的列可展開完整資訊與到期／警告。在列內操作鍵盤，不會觸發全域交易快捷鍵。

## 驗證 / Test plan

以下為本機紀錄，並非雲端 CI 結果。

- 完整 Vitest：4197 passed、0 failed，另有 2 項既有 native 測試 skipped。Node ETF 測試 10 passed。
- `tsc -b`、`vite build` 通過。
- 在 dev 與 build preview 的兩個搜尋入口，核對過 `櫃買`／`IX0043`、`2330`、`00981`／`009810` 的結果與排序。
- 窄版代號在前：兩個入口於 320 px 核對，命令面板另於 360 px 核對，未遍歷所有尺寸。
- 效能量測：
  - 同資料量下，新排序的 CPU p95 差異為 −4.63%～+4.43%。
  - 名稱與別名覆蓋增加後，相對舊資料的 CPU p95 增加 46.93%～62.64%，未達原定 +10% 門檻。
  - 各輪 Node CPU p95 都低於 2 ms，目前僅接受用於本機草稿與 dev。
  - 瀏覽器整體延遲與報價負載尚未驗收。

### 已知限制

- 原生版暫停官方名稱更新，改顯示券商或內建名稱。原因是公開名稱來源在原生環境的 cookie 隔離尚未證明。這不影響原有的券商商品查詢。
- 台指相關商品目前列到次月（R2），不涵蓋所有遠月。
- 以下項目尚未驗收：
  - 正式同源路由部署
  - 原生精確候選版
  - 乾淨環境與雲端 CI
  - 原生 IME 與螢幕報讀器
  - 夜盤實際 Tick／BidAsk（週六僅確認 SSE heartbeat，不代表夜盤通過）
- 部分低優先 UX、舊 IND101 相容性與其他尺寸限制仍在 QA 追蹤，詳見 [產品搜尋擴充驗收紀錄](../qa/product-search-expanded-acceptance.md)。
