# 台灣權證交易規則（Pro 下單用）

查證日：2026-11-09。範圍是上市（TWSE）與上櫃（TPEx）的認購／認售權證，含牛熊證。
每條規則都對應 `src/lib/warrant-rules.test.ts` 的同名 `describe`，改規則時兩邊一起改。
程式的單一判斷來源是 `src/lib/warrant-rules.ts` 與 `src/lib/contract-market.ts`。

## 官方條文沒有明文的部分

- **信用交易與現股當沖**：TWSE 當沖專區的標的範圍指的是標的股票，不是權證本身，官方條文沒有找到權證可以融資融券或現股當沖先賣的明文。產品負責人 2026-11-09 確認權證不能信用交易、也不能現股當沖先賣，Pro 對權證**只開放現股**，信用與現沖先賣一律拒絕。一般的當日先買後賣（兩筆現股）不受影響。
- **盤後定價交易**：TWSE 交易制度頁寫「除公債外之其他上市有價證券」，字面上可能包含權證，但沒有明文。Pro 的閃電與下單面板本來就沒有盤後定價選項，本次不新增。
- **外國成分 ETF、黃金現貨為標的的權證**：這類權證也無漲跌幅，但代號第六碼是一般國內標的的數字，無法從代號分辨。這類權證送市價會被交易所退回（不會成交），Pro 目前不攔；之後若 sidecar 提供漲跌幅或標的種類欄位再補。
- **上櫃權證買賣辦法條文**：櫃買法規網站本次沒有取得權證買賣辦法全文；升降單位、交易單位、無漲跌幅、零股限制都是依櫃買中心官方交易制度頁與簡報，內容與 TWSE 一致。

## App 範圍（不是交易所規則）

- 閃電下單的觸價單與自動停損停利：觸價引擎只認股票／期權，權證先明確停用並提示，不會改成無保護送出。
- 網格下單與整零價差維持不支援權證（整零價差需要零股）。
