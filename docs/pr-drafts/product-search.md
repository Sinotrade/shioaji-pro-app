# 商品搜尋修正 PR 草稿

修正櫃買指數中文搜尋，並讓精確股票名稱或代碼能列出同標的期貨及權證。本稿與程式差異僅保留在本機，未推送、未建立 GitHub PR，也未合併或發布。

## PR 資訊

- 建議標題：`fix(search): 補齊櫃買指數並支援同標的商品搜尋`
- Base：官方 `main`，`be4cbd3073df2625db0d51f767c812a27f79cb8e`。
- 本機分支：`codex/product-search-related`，不堆疊報價欄 PR。
- 原始問題：[how0531/1017 問題說明](https://github.com/how0531/1017/blob/8b99a29/docs/issue-otc-index-search.md)。

## 原因

1. 指數名稱搜尋只用 27 筆寫死的清單，漏掉 `IX0043`，且每筆交易所皆寫成 `TSE`。直接代碼查詢走另一條路，所以輸入 `IX0043` 找得到，中文名稱卻找不到。
2. 同標的商品只在特定類型關鍵字出現時查詢；兩個搜尋入口未開啟權證。模糊搜尋的第一筆股票還會被當作精確標的，造成錯誤關聯。
3. 來源共用失敗鏈、結果直接截斷，以及輸入變更後保留舊建議，分別造成可用結果被連坐、現股被衍生商品擠掉與選錯上一輪商品的風險。

## 修改內容

- 新增帶交易所的指數搜尋資料，共 38 筆。保留既有上市類股，加入實查的櫃買指數、7 筆櫃買類股、未含金融／電子指數及 `TAIWANVIX`。不將這份清單描述成完整指數目錄。
- 「台積電／臺積電／2330」精確命中現股時，依 `underlying_code` 查同標的期貨與權證，不以 `target_code` 猜標的。
- 混合清單保留精確股票與不同商品的名額。期貨保留近月／次月代碼和完整合約；「2330 選擇權」也能搜尋 `CDA/CDO`，最多展開 4 個根商品。
- 權證同時檢查到期日與最後交易日；日期不足標示「交易日期待確認」，不宣稱可交易。
- 同類請求共享執行中的 Promise，成功快取 60 秒，各快取最多 16 項，依 API base 與台灣日期分隔。失敗不快取，來源切換時拒收舊結果。
- 部分來源失敗時保留其他可用結果；無結果且有來源錯誤時顯示可重試的搜尋失敗，不偽裝成找不到商品。
- 自選清單與命令面板啟用權證搜尋，傳遞商品型別並保留搜尋取得的完整合約。改輸入即撤掉舊建議；名稱搜尋待決時不允許 Enter 誤選舊商品。
- 權證在主視窗與彈出視窗的閃電下單、鋪單、整零價差面板均被阻擋，避免被誤當期貨。不增加新的權證交易功能。
- 修正 3 個既有測試的環境隔離：模擬全域 `fetch`，並清理觸發引擎測試的計時器。未修改服務管理或交易實作，也未弱化斷言。

## 使用情境

| 輸入或動作 | 修正後行為 |
| --- | --- |
| 櫃買／櫃買指數 | 找得到 `IX0043`，商品身分為 `IND/OTC` |
| 櫃買半導體 | 找得到 `IX0053`，不誤用上市半導體代碼 |
| 台積電／2330 | 同時列出現股、台積電期貨、小型台積電期貨與權證 |
| 2330 選擇權 | 列出 `CDA` 與 `CDO`，不是只取第一個同名根商品 |
| 臺指選擇權波動率指數 | 找到 `TAIWANVIX`，不被拆成一般選擇權查詢 |
| 輸入新名稱後立刻 Enter | 不會跳到上一輪商品 |
