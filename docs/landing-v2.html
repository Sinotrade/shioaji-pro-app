看盤、下單、跑回測，在同一個視窗做完。

Shioaji Pro 是用永豐金證券 Shioaji API 做的桌面交易軟體，免費下載。介面程式碼全部公開，也是學 Shioaji API 的範例。第一次開啟連的是模擬環境。

02

下單

現股、零股、在 K 線上掛單，自選、持倉和委託放在旁邊。

點價格就下單

價格梯標出目前成交價，開啟「跟隨」會自動置中。點左邊買單欄掛買單、點右邊賣單欄掛賣單，委託直接標在那一格；點自己的委託標記就刪單。剛開啟時是鎖住的，要先按「啟用」才會送單。

  1. 按「啟用閃電下單」解除鎖定
  2. 成交價上下跳動，藍色列標出目前價位
  3. 點左邊買單欄，在 2,545 掛一張買單
  4. 成交後委託標記消失，持倉和均價顯示在下方
  5. 在右邊掛一張賣單，點那個標記就刪單

整股、零股，同一個面板切換

切到零股，數量單位從「張」變成「股」，五檔換成零股行情。零股用現股限價、當日有效送出，每筆最多 999 股，可以減量或刪單，不能改價。每檔股票會記住你上次選哪一種。

  1. 單位切到「盤中零股」
  2. 數量直接輸入股數，例如 35 股
  3. 五檔換成零股行情，只能用 ROD，送出前再看一次

在 K 線上掛單、拖線改價

先選「點價買」或「點價賣」，再點圖上的價位，照設定的數量掛限價單。委託會畫成一條線，整股委託拖到新價位放開就是改價。停損、停利也能掛在圖上，由 App 盯價，觸價時送單，所以 App 要保持開著。

  1. 選「點價買」
  2. 點圖上的 2,525，掛一張限價買單
  3. 把委託線拖到 2,530，放開就改價
  4. 選「停損」點 2,510，App 盯價、觸價時送單

自選和帳務放在旁邊

自選清單有迷你走勢，成交時會閃一下。持倉損益跟著行情更新。要截圖或直播前，打開「隱私」遮住帳號，再打開「遮金額」把金額和持倉數量藏起來。

  1. 自選股有成交時，那一列會閃一下
  2. 持倉損益跟著行情更新
  3. 打開「隱私」和「遮金額」，帳號只留末兩碼，金額全部遮起來
03

版面自己排

面板可以拖曳、調整大小，也能多開。一張 K 線看大盤，一張看個股，閃電下單放右邊，存成「盤中」版面，下次直接載入。多螢幕的話，把面板彈出成獨立視窗。

面板可以跟著自選切換商品，也可以鎖定在一檔。

  1. 從「新增面板」挑要的面板
  2. 自選、K 線、閃電下單依序放上去
  3. 拖邊框調整大小
  4. 再開一張 K 線，上下各看一檔
  5. 存成「盤中」版面
04

交代一句話，讓 Agent 幫你做

桌面版內建 AI Agent，可以接 Claude，或是用 ChatGPT 訂閱登入的 Codex。它看得到行情、持倉和你的版面，能幫你查資料、寫策略、跑回測。AI 服務的費用依你用的方案計算。

交易權限由你決定

交易權限分三種：唯讀、逐筆確認、受控自動。逐筆確認時，Agent 只會送出預覽，你按確認才送單；受控自動要你先授權，而且一樣受 App 的風控限制。Shioaji 的 API 金鑰存在你的電腦。

常做的流程可以存成技能，下次輸入「/名稱」就跑。也可以排程，例如每天開盤前檢查一次持倉。

  1. 用一句話說你要什麼
  2. Agent 用 App 的工具讀 K 線、存策略、跑回測
  3. 回測結果直接開在 App 裡
  4. 逐筆確認模式下，它只送預覽，等你按確認
05

寫策略、回測、找參數桌面版

策略用 JavaScript 寫，和自訂指標用同一套 ta 函式庫。回測依你的設定算進手續費、交易稅和滑價；訊號在收盤確認，符合成交條件時最快在下一根開盤成交。策略如果讀到未來的資料，引擎會擋下來。

一次可以跑整個自選清單，看每一檔的結果。參數最佳化支援格點和隨機搜尋，訓練期和測試期的成績分開列，比較容易看出是不是只對過去有效。

  1. 寫策略：快慢均線交叉進出場
  2. 回測，算進手續費、稅和滑價
  3. 格點搜尋參數，每一格是一組回測
  4. 訓練期和測試期分開比較
06

缺什麼面板，自己做一個

介面的程式碼全部公開（AGPL-3.0）。fork 下來，跟 Claude Code 或 Codex 說你要什麼，例如「一個列出自選股今天爆量的面板」，它會參照現有面板的寫法加上去。你檢查、建置過後，新面板就能和其他面板一起拖拉排版。

改好的介面可以在瀏覽器跑，也可以建置後上傳到 shioaji server，變成你自己的 App（目前 server 重啟後要重新上傳）。只想加一條線的話，用 App 內的自訂指標就夠了。

  1. 告訴 coding agent 你要的面板
  2. 它參照現有面板新增、登記檔案，你檢查後建置
  3. 新面板出現在版面裡，可以拖拉、存檔
  4. 建置好的介面上傳到 shioaji server，當成自己的 App
07

這個專案就是 Shioaji API 的範例

想知道怎麼用 Shioaji 接即時行情、送單、查帳務、處理斷線重連？這個 repo 就是透過 Shioaji server 的 HTTP API 與 SSE 寫成的完整介面，下表是可以直接參考的地方。AI Agent 和回測引擎在桌面版的私有模組，不在這個 repo。

08

常見問題

要付費嗎？

App 免費下載。交易手續費依永豐金證券的一般規定。

需要永豐金證券帳戶嗎？

需要。登入用的是永豐金證券的 API Key。

模擬環境會用到真的錢嗎？

不會。模擬環境的委託不會送到交易所。

期貨、選擇權也能交易嗎？

可以。閃電下單、組合單、T 字報價和損益圖都有，這頁先介紹證券。

桌面版和 Web 版差在哪？

看盤和下單介面兩邊一樣。桌面版內建 shioaji server，另外有 AI Agent、策略回測、系統匣和自動更新；Web 版要自己啟動 shioaji server。

AI Agent 要另外付費嗎？

App 不收費。AI 服務的費用依你用的 Claude 或 ChatGPT 方案計算。
