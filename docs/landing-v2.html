AI Agent 用的是你自己在 App 設定裡登入的 AI 服務，用量算在你的方案。

Agent 能做的事・1

它看你操作，學會你的流程，下次替你做好

App 在你的電腦記錄最近的操作：看了哪些商品、開關哪些面板、套用哪個版面、下了什麼單。紀錄只存在本機，不會上傳。

開啟「工作流程觀察」後，常駐的 Agent 每天看一次這些紀錄。同樣的步驟重複出現兩三次以上，就存成技能並通知你，例如「早盤例行檢查」；下次輸入「/早盤例行檢查」，它就照做一遍。你自己改過的技能，它不會覆寫。

這個任務只有分析權限，不會下單。開啟前會先跳出核可卡，寫清楚排程、環境，以及每次執行會用到你的 AI 額度。

  1. 任務頁的「工作流程觀察」按「檢視並開啟」
  2. 核可卡列出排程、權限、環境與 AI 額度，按「開啟」
  3. 學到新流程時，存成技能並通知你
Agent 能做的事・2

你想要的功能，不必再等券商，它直接做給你

不用等券商改版，也不用自己一個一個拖。跟 Agent 說你要怎麼看盤，它用 App 的工具套版面、加面板、把面板鎖在某一檔；要的指標沒有內建，它用 JavaScript 寫成自訂指標，掛到你指定的 K 線圖上，之後也能幫你調參數或拿掉。

需要券商沒有的表，例如持股的除息日和殖利率，它可以開瀏覽器查、寫程式整理成檔案或網頁。要做成 App 裡的面板，可以修改公開的介面程式碼，上傳到 shioaji server 當成自己的 App。

  1. 用一句話說你要的版面
  2. Agent 套版面、加閃電下單和五檔
  3. 寫一條均量線，掛到台積電的 K 線圖
Agent 能做的事・3

從一個想法到一份回測，不用寫一行程式

貼一篇文章或講一個交易想法，Agent 把它寫成策略，用歷史 K 線回測，再用參數最佳化找最好的參數。它會把樣本內和樣本外的成績分開報告，告訴你這組參數是不是只對過去有效。回測依你的設定計入手續費、交易稅和滑價，訊號收盤成立、次根開盤成交，策略讀到未來資料會被擋下來。

在對話裡完成研究

  1. 用一句話說你的想法
  2. Agent 寫策略、回測、跑參數最佳化，每一步都列出來
  3. 樣本內外分開報告，提醒過度擬合
  4. 結果直接開在「策略回測」面板

研究和回測只模擬成交，不會送出委託。

自己動手也可以

「策略回測」面板可以直接寫策略（內建雙均線範例）、選商品與期間、執行回測，結果有權益曲線、報酬、回撤、勝率、獲利因子；展開「最佳化研究」設定參數範圍和樣本內外期間。可以單商品或多商品執行。

  1. 新策略：快線、慢線兩個參數
  2. 選 2330、日 K、730 天，按「執行回測」
  3. 權益曲線、報酬、回撤、勝率一起出來
  4. 展開「最佳化研究」，設定參數範圍與樣本內外期間
Agent 能做的事・4

你訂好比例，它替你看住資產配置

你先定好目標比例，例如股票 60%、債券 ETF 30%、現金 10%。Agent 讀你的持倉和帳戶餘額，算出現在偏離多少，列出要買賣哪幾檔、各多少、預估成本。也可以建立排程任務定時檢查，例如每天開盤後看一次，偏離超過 5% 才通知你。

比例和規則都由你決定，Agent 不推薦標的。要調整時，它一筆一筆送出下單提案，每一筆下單都需要你的核可；正式環境改用獨立的核可視窗。

  1. 說出你的目標比例
  2. Agent 讀持倉、帳戶與報價，算出偏離
  3. 列出調整清單，送出下單提案，每筆都需要你的核可
  4. 建立定時檢查的排程任務
Agent 能做的事・5

開盤前和收盤後，它先替你整理好

建立一個排程任務，寫好要它做什麼：每天 08:30 整理持股與自選的夜盤、美股、重大公告和今天要注意的價位；收盤後整理今天的成交、損益來源，和你的計畫差在哪。做完它會通知你，結論留在「紀錄」頁。

任務可以每天定時、每 N 分鐘、到價觸發，或在委託／成交時觸發，每個任務有自己的交易權限和執行時間上限。

任務綁定模擬或正式環境，只在相符的環境執行；模擬的任務不會跑到正式帳戶。每次執行都會用到你的 AI 額度，畫面上會寫清楚。

  1. 新增任務，寫下要它做什麼
  2. 設定每天 08:30、交易權限「僅分析」
  3. 時間到自動執行，做完通知你，結論留在紀錄頁

為什麼可以放心交給它

你負責判斷，它負責把事情做完。每一筆下單都需要你的核可。

  • 交易權限三選一僅分析：只查詢不下單。逐筆確認：每一筆下單都需要你的核可。Auto：你在正式環境先授權一次，只在這次連線、目前帳戶有效；切帳戶、停止 Agent 或重開 App 就失效。
  • 正式環境有獨立核可視窗由 App 另外開啟的獨立視窗，Agent 無法代按。報價跳動或超過 15 秒沒核准，這筆退回，請它依最新報價重新提案。
  • 模擬與正式分開排程任務綁定環境，只在相符的環境執行。
  • 風控上限 Agent 也要遵守單筆數量、單筆金額、限價偏離、單次下單筆數都有上限，市價單需要你的核可；Auto 也不例外。
  • 每一步都列出來它查了什麼、存了什麼、送了什麼，都在對話裡逐列顯示。
  • 不會重複送單每筆委託只送一次；結果不明時列為「交易結果待核對」，由你核對後結案，不會自動重送。

看盤下單，本身就做得夠好

就算不用 Agent，Shioaji Pro 也是一個完整的台股看盤下單 App：現股、零股、在 K 線上掛單，自選、持倉、委託放在旁邊。

點價格就下單

閃電下單的價格梯標出目前成交價，開「跟隨」會自動置中。點左邊掛買單、點右邊掛賣單，委託標在那一格，點標記就刪單；成交後那一格顯示實心的成交數量，上方顯示持倉和損益。剛開啟時是鎖住的，要先按「啟用閃電下單」。

  1. 按「啟用閃電下單」解除鎖定
  2. 點買單欄的 2,545，掛一張買單（空心標記）
  3. 成交後變成實心數量，上方出現「多 1張 @ 2,545」
  4. 在賣單欄掛一張，點標記就刪單

整股、零股，同一個面板切換

下單面板的「單位」切到盤中零股，數量從「張」變成「股」；零股只能限價 ROD，市價、IOC、FOK 會停用。閃電下單也能切零股，五檔與成交改看零股行情。每檔股票會記住你上次選哪一種。

  1. 下單面板的單位切到「盤中零股」
  2. 數量改成 35 股，市價、IOC、FOK 停用
  3. 閃電下單切到零股，價格梯改看零股五檔

在 K 線上掛單、拖線改價

按工具列的「點價買」或「點價賣」，再點圖上的價位，就照設定的數量掛一張限價單，點完自動回到看盤模式。委託畫成一條線，整股委託拖到新價位放開就是改價。停損、停利也掛在圖上，由 App 盯價、觸價時送單，所以 App 要開著。

  1. 按「點價買」
  2. 點圖上的 2,525，掛一張限價買單
  3. 把委託線拖到 2,530，放開就改價
  4. 按「停損」再點 2,510，掛上停損

自選和帳務放在旁邊

自選清單有迷你走勢，成交時那一列會閃一下；持倉損益跟著行情更新。截圖或直播前，到「設定 › 音效與隱私」打開「帳號遮蔽」和「金額遮蔽」，帳號只留末兩碼，數量、損益、權益都會遮起來。遮蔽只影響畫面，不影響下單和查詢。

  1. 自選股有成交時，那一列閃一下
  2. 持倉損益跟著行情更新
  3. 設定裡打開「帳號遮蔽」和「金額遮蔽」

    回 API 管理頁按「下載憑證」，得到 Sinopac.pfx。在 App 右上角「伺服器」開「伺服器設定」：下次啟動環境選「正式環境」，選擇 Sinopac.pfx、填憑證密碼，按「儲存並重啟」。API Key 要有「正式環境」權限，簽署和測試都通過，就能正式下單。

    待確認：憑證密碼在哪裡設定，官方文件沒寫清楚；App 的提示是「下載時設定」。

步驟依 Shioaji 官方文件：API Key 與 簽署與測試 整理（2026-10-09）。網站可能改版，以永豐金證券網站實際畫面為準。

常見問題

需要先開戶嗎？

需要永豐金證券帳戶，登入用的是你在永豐金證券網站申請的 API Key。要交易期貨、選擇權，另外需要期貨帳戶。

模擬環境和正式環境差在哪？

模擬環境的委託不會送到交易所，不會動到真的錢，第一次開啟預設就是模擬。正式環境要匯入憑證，委託會動用真實資金。

資料和金鑰存在哪裡？

API Key、Secret Key 和憑證密碼存在你電腦的 App 資料夾，不會上傳。操作紀錄也只存在本機。

AI Agent 會不會自己亂下單？

不會。交易權限預設要逐筆核可，每一筆下單都需要你的核可；也可以設成只能分析、完全不下單。另外有單筆數量、金額等風控上限，Agent 也要遵守。

支援哪些商品？

台股上市、上櫃的現股與盤中零股，以及期貨、選擇權。這頁以股票為主介紹。

Windows、Linux 能用嗎？

可以。Shioaji Pro 是為 Mac 打造的跨平台 App，Windows 10／11 和 Linux 也有安裝檔，功能相同。
