# V9 研究版：當沖多空10（2026-10-07）

## 用途與範圍

獨立入口：短線選股 → 當沖多空10。原選股評分、日K波段及 MACD 45／117／17 等既有圖表參數不變；研究模式另修正既有排行榜請求方向。正式模式沒有新入口、不啟動新掃描、保留原排行參數；全程研究唯讀，不下單、不新增逐筆訂閱。

候選池仍為自選＋排行榜最多40檔。本模組交錯取自選、漲幅、跌幅、成交量與成交額排行，避免量排行先占滿40檔導致空方失去候選；不代表全市場排名。多空各最多10檔，空名額不補不合格股票。

Shioaji 的 `ascending=true` 實際代表大到小，`false` 代表小到大，不能依參數名稱推斷。四個新排行為漲幅true、跌幅false、成交量true、成交額true。2026-10-07官方文件及sidecar實測均確認此語意；原先false量／額排行取得的是最低量／額，不是最活躍股票。

## 兩層名單

1. **盤中條件已確認**：當日行情、資格、流動性、價差、封閉5分K、同時段量能均通過。仍不是下單建議、可成交或報酬保證。
2. **前一交易日觀察**：已收盤日K的量價／趨勢／波動候選。RVOL、VWAP、即時券源仍待盤中核對，不冒充今日確認。此層使用嚴格小於評估日期的日K；收盤後也不能把此層誤讀為今日收盤選股，每列顯示實際日K日期。

評估時間以台北時間計算；研究窗口09:15～13:25，EMA8需要8根當日封閉5分K，因此最早09:40產生盤中確認。其他時段不保留「目前已確認」名單。週末不產生確認；尚無完整官方休市日曆，非週末休市由當日契約／行情／分鐘來源條件保守擋住。

## 研究預設（尚未校準最佳參數）

| 檢查 | 預設 |
|---|---|
| 範圍 | 台灣上市／上櫃、TWD、普通股4碼；排除ETF、權證、期貨等 |
| 資格 | 券商契約更新日＝今日；暫停交易明確為否、處置等級明確為0 |
| 多／空 | 多方Yes或OnlyBuy；空方僅Yes，未知資格不通過 |
| 歷史 | 至少22根已收盤日K；最新根不逾7自然日；收盤與今日參考價差異不得超過0.5%，否則待確認資料或除權息 |
| 流動性 | 前20交易日平均成交金額**估值**≥1億元：收盤價×成交張數×契約unit，非精確成交額 |
| 波動 | 前14日平均True Range／前日收盤＝1%～8%，不是Wilder平滑ATR |
| 日趨勢 | 多：價在MA20上、MA5>MA10、MA20上揚；空為鏡像；完整5>10>20排列只增加同一趨勢組分數 |
| 前日觀察 | 前日量／前5日平均量≥1.2倍，前日價格延續趨勢方向 |
| 報價 | 同商品、同交易所、今日、無未來時間、來源時間距今≤180秒；正值成交、買賣價量完整 |
| 價差 | 買賣價不鎖定／交叉，價差≤0.4% |
| 開盤區間 | 完整09:01～09:05分鐘形成OR5；最近封閉5分K突破高／跌破低 |
| 盤中方向 | 封閉5分K、當日VWAP及EMA3／8同方向；最新快照仍在突破點與VWAP正確側 |
| RVOL | 今日開盤至最近封閉5分時點的累積量／最近20個已驗證日K中至少14個完整同時段的平均量≥1.5倍 |
| 不追價 | 距VWAP≤3%、距OR突破點≤2%、距漲跌停>0.5% |
| 空方券源 | 正數、同日且≤180秒，帳戶／額度與成交能力仍需自行核對 |

沿用外層極端排除：多方RSI>85、20MA正乖離>15%、單日漲幅≥9%、向上跳空≥8%、3日漲幅≥22%，任何一項不進候選。空方採對稱過冷／追空排除。風險檢查可看最新快照，突破確認只看已封閉K，避免未收K觸發。

VWAP是分鐘HLC3×成交量的加權近似、每日09:00重設，不是逐筆成交金額的精確VWAP。原始分鐘缺漏可能只是無成交；本研究不判定為斷線，但不拼接或補0進確認。

## 分數與資料界線

盤中優先度最多100分：流動性15、RVOL25、盤中方向20、開盤突破15、日趨勢15、相對大盤強弱10。不是勝率；缺大盤即時資料不加相對強弱分，不用舊大盤冒充。先過硬性條件、再排序取最多各10。

Snapshot.volume_ratio是累積量與昨日全日量的比值，**不得代替同時段RVOL**。缺14日完整分鐘窗時只保留符合前日條件的觀察列，不新增第二趟歷史下載補名額。

行情與券源均保留來源時間，不能把HTTP抓取完成時間寫成資料時間。2026-10-07實機唯讀查到行情12:48及券源04:49的無時區字串；券源有正數但時間語意未驗證，現有規則保守不確認空方，沒有自行加8小時使其過關。需確認sidecar時間契約後再加對應wire回歸，不能透過放寬時間門檻繞過。

## 請求與驗證

只有打開新頁籤才啟動四個排行榜，原頁籤掃描暫停；每120秒更新，掃描尚未完成不被自動輪詢反覆取消。每15秒只重算來源有效期，不拉歷史。沿用日K已有下載與背景分鐘，四檔並行，及時擷取24商品LRU可能淘汰的分鐘；快照放在歷史讀取完成後取得。資格刷新限研究列，不覆寫正式共用契約快取。

尚待：真實研究頁／原生App畫面與平板驗收、官方休市日曆、權息／分割調整、全日來源缺口稽核、券源時區契約。使用正規市場資料仍不等於策略已有獲利能力。

下一階段評估用多空分開的走勢外樣本：比較RVOL1.5/2、OR5/15、價差0.2/0.4%，納入雙邊手續費、當沖交易稅、滑價、限價不可成交、券源與回補成本；固定樣本外後看成本後期望值、最大回撤、成交覆蓋率及每天候選數，不只看勝率或挑成功圖。
